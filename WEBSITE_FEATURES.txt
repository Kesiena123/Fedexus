--------------------------------------------------------------------------------

- 13 tracking statuses with 8-step visual progress timeline
- Statuses: Created, Pending, Picked Up, In Transit, Arrived at Facility, Customs
  Clearance, Out for Delivery, Delivered, Delayed, On Hold, Cancelled, Returned, Exception
- Copy tracking number to clipboard
- Print tracking page

- Responsive map with debounced resize handling

11. ADMIN AUTHENTICATION & SECURITY
--------------------------------------------------------------------------------

- Admin Login (GET|POST /admin/login) with:
  * Arithmetic CAPTCHA (server-side hashed, cache-backed)
  * Rate limiting (5 attempts per 900 seconds per email + IP)
  * Suspended account detection
  * Two-Factor Authentication (6-digit code via notification + email)
  * Trusted device recognition (device fingerprint, 30-day window)
  * Session invalidation on logout

- API-based Admin Login (POST /api/admin/auth/login) with:
  * IP allowlist/blocklist enforcement
  * Sanctum token with configurable session timeout (default 30 min)
  * Device name and fingerprint tracking

- Two-Factor Authentication:
  * Enable with 6-digit confirmation code
  * Disable with password re-entry
  * 10-minute code expiry

- Role-Based Access Control (RBAC):
  * 7 roles: super_admin, admin, manager, support, warehouse, driver, customer
  * 11 fine-grained permissions:
    - dashboard.view, users.view, users.manage
    - shipments.view, shipments.create, shipments.approve, shipments.update,
      shipments.delete, shipments.attachments.manage
    - payments.manage, audit.view
  * Per-user permission overrides (grant/revoke on top of role defaults)

- Security Protections:
  * Self-modification protection (admins cannot modify own account from control)
  * Super admin protection (only super admins can modify other super admins)
  * High-risk access protection (only super admins can modify users with users.manage)
  * IP allowlist/blocklist via environment variables
  * Admin session timeout (configurable, default 30 minutes)

================================================================================
                         TECHNICAL ARCHITECTURE
================================================================================

- Framework:        Laravel (PHP) with Blade templating
- API:              Dual architecture — Blade server-rendered pages + RESTful JSON API
- Authentication:   Session-based (Blade) + Sanctum tokens (API)
- Real-time:        Broadcasting events (ShipmentUpdated, MessageSent)
- PDF Generation:   DomPDF with HTML5 parser
- Barcode:          Picqer barcode library (Code 128 SVG)
- Geocoding:        OpenStreetMap Nominatim with local cache
- Frontend:         Tailwind CSS, Alpine.js, Vite bundler
- Maps:             Leaflet.js with OpenStreetMap tiles
- Database:         23 models, 14 migrations
