==================================================
USE LARAVEL CONFIGURATION CORRECTLY
==================================================

Follow Laravel best practices.

Environment variables should be accessed through configuration files.

Preferred architecture:

.env
↓
config/*.php
↓
Application Code

Do NOT scatter env() calls throughout controllers, models, services, or Blade files.

For example:

.env

APP_NAME="Global Express Logistics"
APP_URL=https://example.com

config/app.php

'name' => env('APP_NAME', 'Laravel'),
'url' => env('APP_URL', 'http://localhost'),

Application code should use:

config('app.name')
config('app.url')

instead of directly calling:

env('APP_NAME')
env('APP_URL')
